# Marca UC — reglas para todos los formatos

Autoridad primaria: `assets/manual-marca-uc.pdf`. Aplicar también los templates oficiales incluidos. No reinterpretar la marca si el manual o el template ya resuelven el caso.

## Reglas obligatorias
- En contexto chileno usar marca madre nacional.
- Respetar lockup, proporciones, zona de seguridad y tamaño mínimo.
- Nunca girar, cortar, deformar, usar como marca de agua ni superponer texto sobre la marca.
- Mantener contraste suficiente y usar sólo variantes/colores autorizados por el manual.
- Tratar facultad, escuela, instituto, centro, programa, doctorado, proyecto o unidad como **denominación** cuando corresponda; no inventar una nueva marca.
- No colocar una denominación junto al escudo de forma que reemplace o compita con el nombre de la Universidad.
- En cobranding, aplicar las reglas del manual y mantener jerarquías equivalentes cuando corresponda.

## Principio de diseño
La identidad UC debe vivir en el sistema: marca, retícula, tipografía, paleta, márgenes, footer, proporciones y disciplina editorial. No convertir el logo, el azul o las bandas en decoración repetitiva.
