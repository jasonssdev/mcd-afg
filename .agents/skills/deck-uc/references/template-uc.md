# Template UC Chile — reglas de uso

Fuente local obligatoria: `assets/template-uc.pptx`, entregada por el usuario.

## Prioridad

Cuando el usuario pida una presentación UC, esta plantilla es la **fuente de identidad visual primaria y obligatoria**. Mantener sus elementos institucionales; no sustituirlos por una marca alternativa.

## Estructura observada en la plantilla

La plantilla es 16:9 y contiene patrones para portada institucional, título de presentación, contenido, fotografía y cierre. Utiliza el lockup **UC | Chile**, banda cromática inferior, azul institucional y tipografía Calibri en sus placeholders.

## Regla de fidelidad

1. Mantener proporciones, márgenes institucionales, logo/lockup, banda inferior y jerarquías esenciales.
2. No sustituir el lockup institucional por otro escudo cuando se use la identidad del template.
3. Usar los layouts del template como primera opción para portada, fotografía y cierre.
4. En slides de contenido, el template funciona como **sistema de identidad**, no como una cárcel de layout: se pueden construir diagramas e infografías editoriales cuando el contenido lo exija, siempre heredando marca, geometría, tipografía y paleta.
5. Evitar interpretar "fidelidad UC" como grandes cajas azules repetidas. Fondo blanco, aire, líneas finas y acentos controlados pueden ser más fieles a una presentación profesional.
6. No usar gradientes, sombras, 3D, pills o decoración ajena al lenguaje institucional salvo petición explícita.

## Storytelling + diseño

`references/storytelling.md` define qué historia contar y en qué orden. `references/visual-design.md` define cómo traducir cada relación conceptual a una composición profesional. Nunca seleccionar un layout antes de definir action title, evidencia, relación conceptual y arquetipo visual.
