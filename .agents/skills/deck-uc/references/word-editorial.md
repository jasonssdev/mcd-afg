# Modo WORD / INFORME / TESIS

Referencias institucionales:
- `assets/word-uc-corporativa.docx`: master institucional principal.
- `assets/word-uc-unidad.docx`: variante para unidad específica.
- `assets/word-uc-sin-texto.docx`: recurso auxiliar limpio.
- `assets/manual-marca-uc.pdf`: autoridad normativa.

## Principio
No repetir la hoja carta corporativa literalmente en cada página de una tesis. Extraer el sistema institucional y construir un sistema editorial para documentos extensos.

## Dos capas
### Institucional — no improvisar
Marca, lockup, proporciones, zona de seguridad, denominaciones, colores, ubicación institucional, datos de unidad y reglas de cobranding según manual/template.

### Editorial — diseñar según el documento
Retícula, márgenes de lectura, H1/H2/H3, cuerpo, captions, tablas, figuras, diagramas, destacados, numeración, blancos, secciones y navegación.

## Tipos de documento
Adaptar estructura a tesis/memoria, informe académico, informe técnico, informe ejecutivo, propuesta, paper/proyecto o documento institucional. No inventar requisitos académicos no entregados por el usuario o su unidad.

## Sistema editorial mínimo
- portada y portadilla cuando corresponda;
- estilos semánticos de Word, no formato manual disperso;
- títulos jerárquicos consistentes;
- cuerpo legible y estable;
- tabla de contenidos si corresponde;
- encabezados/pies y numeración coherentes;
- tablas con jerarquía y reglas ligeras;
- figuras con caption y fuente;
- referencias cruzadas cuando el entorno lo permita;
- páginas de capítulo y anexos;
- control de saltos, viudas/huérfanas y tablas partidas;
- uso de color UC con moderación y función semántica.

## Tesis
La identidad institucional no sustituye las normas formales de la facultad/programa. Si el usuario aporta reglamento o plantilla de tesis, esas reglas académicas prevalecen en estructura, márgenes, portada, citas y secciones, manteniendo la marca sólo donde sea compatible.

## QA Word obligatorio
renderizar -> inspeccionar todas las páginas -> auditar -> corregir -> volver a renderizar -> validar.

Revisar: marca UC, márgenes, estilos, jerarquía, TOC, numeración, encabezados/pies, viudas/huérfanas, saltos, tablas partidas, figuras, captions, referencias cruzadas, resolución, contraste, consistencia, clipping/overflow, páginas vacías accidentales y metadatos. No entregar sin inspección visual del render final.
