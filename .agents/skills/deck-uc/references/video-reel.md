# Modo VIDEO / REEL

Referencia funcional: `assets/reference-video-reel.pptx`.

Este modo produce una presentación audiovisual lista para convertirse en video, reel, cápsula o pieza narrada. No es un deck normal con animaciones agregadas al final.

## Flujo obligatorio
objetivo -> audiencia/plataforma -> duración -> Big Idea -> guion de voz -> beats -> storyboard temporal -> visual por beat -> timecodes -> cues -> animación/transición -> sincronización -> QA audiovisual.

## Plan por slide/escena
Definir:
- propósito narrativo;
- texto de locución exacto o aprobado;
- duración estimada y timecode IN/OUT;
- visual dominante;
- formato de fuente visual: speaker/video 9:16, screen recording 16:9, captura, diagrama, texto cinético, dato, etc.;
- cue asociado a frase/palabra de la locución;
- animación/transición y orden;
- avance manual/automático;
- notas de edición.

## Sincronía
- La frase de locución manda sobre un offset temporal menor: ajustar timing sin alterar contenido aprobado.
- No animar por decoración. Cada aparición debe acompañar una unidad de significado.
- Mantener continuidad visual entre escenas; Morph sólo cuando la transformación espacial sea semántica.
- Diseñar para el formato final solicitado: 9:16, 1:1 o 16:9. No recortar un deck 16:9 para simular reel.
- Respetar safe areas para subtítulos, UI de plataforma y speaker overlay.

## Rigor
Distinguir demostración visual, ejemplo, evidencia y resultado experimental. No presentar una demo como prueba.

## QA audiovisual
Revisar storyboard completo, duración total, densidad de voz, sincronía cue/locución, legibilidad al tamaño final, continuidad, safe areas, ausencia de frames muertos, cortes bruscos, animaciones redundantes y consistencia UC. Corregir y revalidar antes de entregar.
